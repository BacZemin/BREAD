# Extract the region-level results table from a [BreadFit](https://baczemin.github.io/BREAD/reference/BreadFit.md)

Extract the region-level results table from a
[BreadFit](https://baczemin.github.io/BREAD/reference/BreadFit.md)

## Usage

``` r
results(object, ...)

# S4 method for class 'BreadFit'
results(object, ...)
```

## Arguments

- object:

  A [BreadFit](https://baczemin.github.io/BREAD/reference/BreadFit.md).

- ...:

  Unused.

## Value

A data frame with one row per region.
